# NR Jewellers

Informational website for NR Jewellers (NR Elegance Style), Shop No. 45, UTC Millennium Plaza, Shalimar Garden Extension II, Sahibabad. It covers the collections, the shop's story and how to visit. There is no online shopping.

It's a single static page (`index.html`) with no build step, hosted on GitHub Pages.

- Collection photos go in `images/<collection>/` and are listed in the `designs` object near the bottom of `index.html`.
- Design rules are in `DESIGN.md`.
